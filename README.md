# Bright Street General Maintenance & Cleaning Services LLC

A professional, responsive frontend website built for **Bright Street General Maintenance and Cleaning Services LLC**, located in Abu Dhabi.

## 🌟 Features

* **Modern UI/UX Design:** Built with Tailwind CSS and FontAwesome icons for a clean and professional look.
* **Comprehensive Cleaning Services:** Detailed sections covering residential, commercial, post-renovation, and deep cleaning.
* **Pest Control Solutions:** Eco-friendly and certified pest management services across Abu Dhabi's major neighborhoods (Al Danah, Khalifa City, Mohammed Bin Zayed City, etc.).
* **Facility Maintenance & Repairs:** AC servicing, electrical, plumbing, handyman, and painting services.
* **Direct WhatsApp Integration:** Quick booking and customer support buttons integrated via WhatsApp.
* **Fully Responsive:** Optimized seamlessly for mobile, tablet, and desktop screens.

## 🛠️ Technologies Used

* **HTML5**
* **Tailwind CSS**
* **JavaScript**
* **FontAwesome Icons**
